# בודק תצוגה (render-check)

בודק אוטומטי שמוודא שהצופה מצייר כל אחד מ-800 הדפים של `source/siddur.pdf` בדיוק כמו במקור, כולל כל נקודה, פסיק וניקוד.

## איך זה עובד

1. `render-pdfjs.mjs` מצייר כל דף כמו שהצופה מצייר אותו: PDF.js בתוך Chrome אמיתי, עם אותן הגדרות כמו `viewer.js` (הדף `pdfjs-render.html`).
2. `render-refs.mjs` מצייר כל דף בעוד שני מנועים עצמאיים: MuPDF ו-PDFium. הוא גם בודק קודם שקובץ ה-PDF הוא המקורי (SHA-256).
3. `compare.mjs` משווה כל דף של הצופה לשני המנועים, פיקסל מול פיקסל, ומתעלם מהבדלי החלקה זעירים בשולי האותיות.
4. `selftest.mjs` מקלקל בכוונה סימנים קטנים (מוחק, מחליש, מכהה, מזיז) ומוודא שהבודק תופס אותם.
5. `report.mjs` בונה דף דוח עם הצבעה של 2 מתוך 3 בין המנועים.

הרזולוציה היא 216 DPI, כלומר דף A4 הוא 1785×2526 פיקסלים.

## הרצה

מהתיקייה הזו (צריך Node.js ו-Chrome מותקן):

```
npm install
npm run check
```

זה לוקח כ-20 דקות. התמונות והדוח (כ-1.5GB) נשמרים מחוץ לפרויקט, ב-`%USERPROFILE%\Siddur-Render-Check`. הדוח עצמו נמצא ב-`report\index.html` שם.

צריך להריץ שוב אחרי כל שינוי ב-PDF, בגרסת PDF.js או בדרך שבה הצופה מצייר.
